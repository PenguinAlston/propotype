# 企业 AI 知识库管理原型

这是一个可直接在浏览器打开的前端交互原型，用于讨论企业级 AI 知识库的产品结构、组织归属、共享和权限模型。

## 页面

- `index.html`：知识库总览，支持按个人空间、组织部门和企业公共空间浏览。
- `organization.html`：组织架构与部门知识资产视图。
- `permissions.html`：授权主体、下级部门范围、权限继承和授权记录。
- `personal-space.html`：个人知识库、分享和移交部门。
- `department-space.html`：部门知识库管理。

## 本地预览

下载或克隆仓库后，直接用浏览器打开 `index.html` 即可。页面使用原生 HTML、CSS 和 JavaScript，无需安装依赖或启动后端。

## 原型交互

- 左侧导航可切换页面。
- 知识库总览可切换空间分类、部门和列表筛选。
- “新建知识库”可模拟选择个人、部门或企业公共类型。
- 组织架构节点可展开/收起。
- 权限页面可切换授权主体、是否包含下级部门及继承策略。
- 个人空间可模拟分享和移交操作。

## 原型边界

页面中的组织、人员、文档数量及权限数据均为演示用模拟数据，不连接真实组织架构、文件存储、向量数据库或鉴权服务。正式产品需在服务端落实 RBAC + 资源关系授权（ReBAC），并在文档访问、RAG 检索、答案引用打开等链路执行一致的权限校验。
